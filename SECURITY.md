# Security policy

## Supported versions

Security fixes target the latest published release. Pre-release branches and archived versions are unsupported.

## Report a vulnerability privately

Use GitHub's private vulnerability reporting for <https://github.com/nipun-arora/semantic-seo-geek> after the maintainer enables it. Do not open a public issue for an unpatched vulnerability, leaked credential, path traversal problem, unsafe command, or release-boundary bypass.

If the private-reporting button is unavailable, contact Nipun Arora through a public contact method on <https://github.com/nipun-arora> and ask for a private channel without disclosing vulnerability details.

Include:

- the affected version and file;
- a minimal reproduction;
- the expected and observed behavior;
- the practical impact; and
- any suggested mitigation.

The maintainer will acknowledge a complete report when it is reviewed. No fixed response or remediation time is promised.

## Scope

Reports about the validation scripts, install manifests, skill instructions, release exporter, or accidental inclusion of excluded material are in scope. SEO disagreements and unsupported ranking claims belong in ordinary issues unless they create a security or privacy risk.
