# Governance

Semantic SEO Geek is maintained and published by Nipun Arora.

The maintainer makes final decisions about scope, releases, security fixes, licensing, public documentation, and use of the project's name and logo. Decisions prioritize a clean public provenance boundary, accurate claims, provider compatibility, and maintainable workflows.

Issues and suggestions are welcome under [CONTRIBUTING.md](CONTRIBUTING.md). External code and content contributions are not accepted in version 1 while contributor licensing remains unresolved.

Published releases use semantic versioning where practical. A version number does not promise that third-party search systems or agent environments will preserve behavior indefinitely.
